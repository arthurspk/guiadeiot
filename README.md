## :dart: O guia para alavancar a sua carreira

> IoT (Internet das Coisas) é conectar o mundo físico à internet: sensores, atuadores e microcontroladores como Arduino e ESP32 trocando dados por protocolos como MQTT e Wi-Fi, alimentando dashboards, automações residenciais e produtos conectados de verdade. Este guia reúne roadmap, documentação oficial, cursos, livros, canais, ferramentas de prototipagem (simuladores, brokers MQTT, plataformas de nuvem), protocolos e plataformas de conectividade, projetos práticos e um capítulo dedicado a Edge AI/TinyML — tudo verificado e organizado para quem quer sair do primeiro LED piscando até projetos conectados de verdade, por hobby ou como engenheiro(a) de sistemas embarcados.

## 🗺️ Roadmap

- [IoT for Beginners — site do curso (Microsoft)](https://microsoft.github.io/IoT-For-Beginners/) — Currículo aberto de 24 lições cobrindo do "hello world" com sensores até nuvem e Machine Learning aplicado a IoT.
- [IoT for Beginners — repositório (Microsoft)](https://github.com/microsoft/IoT-For-Beginners) — Código-fonte de todas as lições, com projetos para Raspberry Pi, Arduino, Espressif e Wio Terminal.
- [Espressif — ESP-IDF Programming Guide (visão geral)](https://docs.espressif.com/projects/esp-idf/en/latest/esp32/) — Mapa oficial do framework de desenvolvimento nativo para a família ESP32.
- [Eclipse IoT Working Group](https://iot.eclipse.org/) — Panorama dos projetos open source de IoT mantidos pela Eclipse Foundation (brokers, gateways, frameworks de dispositivo).

Trilha resumida: comece simulando circuitos e programando Arduino (C/C++ básico) → migre para ESP32 quando precisar de Wi-Fi/Bluetooth → aprenda a publicar dados por MQTT em um broker → monte um dashboard ou automação (Node-RED/Home Assistant) → avance para protocolos de longo alcance (LoRaWAN) ou automação residencial (Zigbee/Matter) → explore Edge AI para rodar modelos direto no microcontrolador.

## 🤖 IA na prática

IoT e IA convergem no conceito de **Edge AI**: em vez de mandar cada leitura de sensor para a nuvem, o modelo roda direto no microcontrolador (ESP32, Arduino, Raspberry Pi Pico), decidindo localmente com baixa latência, menos consumo de banda e funcionamento offline mesmo sem internet. Essa combinação — assistentes de IA para programar mais rápido e modelos de IA embarcados no próprio dispositivo — é uma das frentes que mais avançou no ecossistema maker entre 2024 e 2026.

**Para aprender e programar mais rápido**
- Cole o código do seu sketch/firmware junto com o erro de compilação (`undefined reference`, pino errado, timeout de Wi-Fi) e peça ao assistente (GitHub Copilot, Claude Code, ChatGPT) para explicar a causa linha a linha antes de aceitar a correção.
- Peça para gerar o "boilerplate" de conexão MQTT/Wi-Fi para uma placa específica (ex.: "ESP32 conectando ao broker Mosquitto com TLS") e depois confira cada linha na documentação oficial do Arduino core para ESP32.
- Use IA para resumir um datasheet de sensor (PDF em inglês, cheio de tabelas de registradores) e extrair só os pinos, endereço I2C e faixa de operação que você vai usar no projeto.
- Peça exercícios com gabarito sobre o tópico que está estudando (ex.: "interrupções no Arduino" ou "deep sleep no ESP32").

**Para rodar IA no próprio dispositivo (Edge AI / TinyML)**
- [Edge Impulse](https://edgeimpulse.com/) — Plataforma com camada gratuita para coletar dados de sensores, treinar um modelo e exportar para C++/Arduino, rodando direto no ESP32 ou em placas ainda menores.
- [Edge Impulse — documentação](https://docs.edgeimpulse.com/) — Guias oficiais de coleta de dados, treinamento e deploy de modelos em microcontroladores.
- [TensorFlow Lite for Microcontrollers (tflite-micro)](https://github.com/tensorflow/tflite-micro) — Runtime oficial do Google/TensorFlow para rodar redes neurais em dispositivos com poucos KB de RAM.
- [ESP-DL (Espressif)](https://github.com/espressif/esp-dl) — Biblioteca oficial da Espressif para inferência de deep learning otimizada para a família ESP32.
- [tinyML Foundation](https://www.tinyml.org/) — Comunidade e conferências dedicadas a IA embarcada de ultrabaixo consumo.
- [Awesome TinyML (lista curada)](https://github.com/gigwegbe/tinyml-papers-and-projects) — Artigos, projetos e ferramentas sobre Machine Learning em microcontroladores.

Casos comuns hoje: detecção de palavra-chave por voz sem depender da nuvem, classificação de vibração/áudio para manutenção preditiva, e visão computacional simples (contagem, presença) com câmeras ESP32-CAM.

**Limites e boas práticas**
- IA erra pinagem e nomes de biblioteca com frequência, principalmente em placas menos populares — confirme sempre no datasheet e na documentação oficial antes de energizar o circuito.
- Um modelo de Edge AI tem RAM e flash limitadas: um modelo que "funciona" no notebook pode não caber no microcontrolador. Teste o tamanho final após a quantização antes de comemorar.
- Nunca cole credenciais de Wi-Fi, tokens de broker MQTT ou chaves de API de nuvem em um prompt de IA.
